AWS · Terraform · GitHub Actions

Deployed by a pipeline.
Not by hand.

This page lives in a private S3 bucket, served through CloudFront over HTTPS, and shipped here by a GitHub Actions workflow that runs terraform plan on every pull request and apply on merge — no console clicks, no manual uploads.

Checking deployment status…  

How this page got here

  1. Push to main

    A commit touching this folder triggers the workflow.

  2. Terraform plan & apply

    Infra (bucket, CDN, alarms) is reconciled via a locked, remote-state apply.

  3. Content synced to S3

    aws s3 sync ships this exact HTML, then the CloudFront cache is invalidated.

  4. Served to you

    Over HTTPS from the CloudFront edge closest to you — this request never touched S3 directly.

What's running underneath

S3 storage

Private bucket, no public access. CloudFront reaches it only via Origin Access Control.

CloudFront delivery

Global CDN, free HTTPS on the default domain, SPA-style fallback routing.

GitHub Actions CI/CD

OIDC federation to AWS — no long-lived access keys stored anywhere.

CloudWatch + SNS observability

Alarms on 4xx/5xx error rate page an SNS topic if this site starts misbehaving.
